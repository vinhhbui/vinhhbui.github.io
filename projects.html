Project 01

Rip Current Detection System

A real-time vision system designed to identify hazardous rip currents from aerial drone footage and support an early-warning rescue workflow.

  • RoleLead Developer
  • TypeApplied research
  • FocusEdge inference

Goal

Turn difficult coastal video into information that can help rescue teams recognize risky water conditions earlier.

Approach

Use YOLOv11 with OpenCV and PyTorch, while accounting for drone motion, reflections, weather, and limited edge compute.

Result

A system concept centered on real-time detection, clear alerts, and deployment constraints—not model accuracy alone.

  • Python
  • PyTorch
  • YOLOv11
  • OpenCV
  • Edge AI
  • Drones

Project 06

Pacman A* Pathfinding

A Pygame agent that searches a maze for an efficient route to food using the A* algorithm.

  • RoleDeveloper
  • TypeAI game agent
  • FocusSearch algorithms

Goal

Make pathfinding behavior visible and testable inside a familiar maze environment.

Approach

Represent the maze as a search space and use A* with a heuristic to evaluate efficient candidate routes.

Result

A visual demonstration of optimal-path reasoning and the effect of search strategy on agent behavior.

  • Python
  • Pygame
  • A*
  • AI Search
